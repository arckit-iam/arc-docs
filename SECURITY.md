# Politique de sécurité

## Signaler un problème

Ne pas ouvrir d'*issue* publique pour une information sensible (secret exposé, valeur d'environnement réelle, erreur d'architecture exploitable).

Utiliser le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**, ou écrire à [etiennsalle@gmail.com](mailto:etiennsalle@gmail.com).

## Bonnes pratiques

- Ne jamais versionner de secrets (mots de passe, jetons, clés privées, keytabs).
- Les exemples de la documentation utilisent des valeurs fictives : les remplacer par vos propres valeurs.
